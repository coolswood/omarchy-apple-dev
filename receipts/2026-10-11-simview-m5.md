# M5 scroll test results

2026-10-11. The Linux simview module now applies scripted vertical drags to a
`ScrollView` content offset. It clamps the offset to the content bounds. A drag
past eight points cancels the row tap. Every frame rebuilds the tree and writes
a new render. This is our model, not Apple's scroll implementation.

## Measurements

- Viewport: 390 by 844 points.
- Demo content: 1103 points high.
- Maximum offset: 259 points.
- Drag distance: 200 points upward. The image matches the 200 point golden.
- Bottom drag: 10000 points upward. The image matches the 259 point clamp golden.
- Top drag: 500 points downward from offset zero. The image matches the root golden.
- Tap on row zero selects row zero.
- Drag from row zero by 200 points scrolls and leaves selection at -1.
- PNG comparisons: 0 differing pixels and 0 channel difference.
